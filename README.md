# Falcora - landing page

- `index.html` : landing page (alamat utama domain, tanpa .html)
- `404.html`   : halaman jika alamat salah
- `.nojekyll`  : agar GitHub Pages menyajikan file apa adanya
- `.htaccess`  : hanya untuk hosting Apache/cPanel, diabaikan GitHub Pages

Harga, link Mayar, dan WhatsApp diubah di bagian CONFIG paling atas `index.html`.
